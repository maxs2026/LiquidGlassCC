# LiquidGlass CC

An Android app prototype inspired by the iOS Liquid Glass Control Center.

This repository is being set up with a Kotlin and Jetpack Compose starter project. It aims to provide a customizable quick-controls panel with a translucent glass appearance, theme options, and configurable controls.

## Status

Starter project setup in progress. The app is not yet a replacement for Android's system Control Center, and an APK has not yet been built or tested.
